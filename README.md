# 이종현 · PLC & Automation Portfolio

Mitsubishi PLC와 물류자동화 제어엔지니어 지원을 위한 독립 GitHub Pages 사이트입니다. 기존 종합 포트폴리오와 분리되어 있습니다.

사이트: https://jonghyeon9084.github.io/plc-portfolio/

Pages 배포: `main` 브랜치의 루트 디렉터리. `assets/Lee-Jonghyeon-PLC-Portfolio.pdf`는 인쇄 검증을 마친 7장 PDF입니다. 내용을 수정한 경우 PDF도 함께 다시 생성합니다.

## 구성

소개 1장 → PLC 2장 → STM32 1장 → 최종 스마트팩토리 1장 → POCO 1장 → 프로필 1장. 브라우저 인쇄는 A4 가로 7장으로 구성했습니다. 모바일에서는 내용에 따라 길이가 조정됩니다.

## 편집 및 실행

- `index.html`: 한국어 콘텐츠
- `styles.css`: 화면·모바일·인쇄 레이아웃
- `design.css`: 독립 디자인. 도면 종이색, 주황색 인덱스, 세로 목차, 영상 중심 첫 화면
- `app.js`: 인쇄, 현재 메뉴 표시
- `assets/`: 공개용 프로젝트 이미지
- 빌드·패키지 설치 없이 정적 서버 또는 GitHub Pages에서 실행합니다.

## 콘텐츠 기준

2026.10.06 제공 이력서와 2026.10.01 구인요청서, PLC 발표자료, 최종 프로젝트의 9/29·9/30 시험 기록을 검토했습니다. PLC·STM32는 공동 담당, POCO 통합 수치는 팀 결과로 표시했습니다. 최종 프로젝트는 개별 주행·도킹 검증과 전체 공정 통합을 구분합니다. Siemens는 학습 방향으로만 표기했습니다.

원본 이력서, 구인요청서, 다른 사람의 개인정보, 내부 네트워크 주소·실행 명령·개발 로그는 공개 저장소에 포함하지 않습니다.

## 이미지

- PLC 실습 장비·HMI: 제공 PLC 프로젝트 발표자료의 실제 이미지
- STM32: 제공 프로젝트 발표자료의 팀 시제품 사진
- POCO: 제공 최종 발표자료의 팀 모니터암 사진

## 시연 영상

- `assets/videos/plc-demo.mp4`: PLC PPT 4쪽에 포함된 79초 시연. 전체 공급·창고 비움·개별 공급 동작.
- `assets/videos/poco-ai-demo.mp4`: AI 1차 결과보고서 PPT 8쪽에 포함된 64초 시연. POCO의 선택 버튼으로 재생하며 2차 통합 결과와 구분합니다.
- 원본 영상 전체 길이를 보존하고 H.264/AAC MP4로 압축했습니다. 자동 재생하지 않으며 브라우저 기본 재생·음량·전체화면 기능을 사용합니다.
- 인쇄에서는 동영상 대신 대표 장면과 웹 시연 링크를 표시합니다.
