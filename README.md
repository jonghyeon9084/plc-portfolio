# 이종현 PLC 제어 포트폴리오

사이트: https://jonghyeon9084.github.io/plc-portfolio/

기존 ROS2 포트폴리오의 흰색과 회색, 타이포그래피, 프로필 사진, 프로젝트 상세 화면과 스크롤 효과를 적용한 PLC 지원용 사이트입니다. 기존 종합 포트폴리오 저장소는 수정하지 않습니다.

## 구성

소개 및 프로필 → PLC 공정 자동화 → STM32 주행 제어 → 스마트팩토리 설비 연동 → POCO 모니터암.

PLC는 공동 개발한 시퀀스와 HMI, Teaching, 동작 시간 측정 및 레지스터 충돌 해결을 중심으로 구성했습니다. ROS2 프로젝트의 1차 통합 시연은 기존 종합 포트폴리오에서 확인한 내용이며, 반복 정밀도 검증 및 지게차 확장은 후속 과제로 구분했습니다. POCO 통합 시험은 팀 결과로 표시합니다.

## 편집 및 실행

- `index.html`: 한국어 콘텐츠와 프로젝트 순서
- `styles.css`, `redesign.css`: 기존 ROS2 포트폴리오의 공통 디자인
- `plc.css`: PLC 제목과 화면 및 인쇄 조정
- `motion.css`, `motion.js`: 스크롤 효과와 읽기 진행 표시. 모션 감소 설정 지원
- `app.js`: 이미지 확대, 현재 메뉴 표시, 영상 중복 재생 방지, 인쇄
- `print.css`: 브라우저 인쇄용 A4 세로 레이아웃
- `assets/`: 실제 프로젝트 사진과 시연 영상

빌드나 패키지 설치 없이 정적 서버로 실행할 수 있습니다. 예: `python -m http.server 8765 --bind 127.0.0.1`

GitHub Pages는 `main` 브랜치의 루트 디렉터리를 배포합니다. 화면 상단의 PDF 버튼은 현재 페이지의 인쇄 및 PDF 저장 대화상자를 엽니다. 기존 `assets/Lee-Jonghyeon-PLC-Portfolio.pdf`는 이전 디자인의 보관본이며, 새 화면에서는 다운로드 링크를 제공하지 않습니다. 새 PDF 파일을 배포하려면 현재 내용으로 생성하고 별도로 검증해야 합니다.

실제 프로젝트 영상은 자동 재생하지 않습니다. 인쇄 시 영상 대신 대표 장면과 영상 링크를 표시합니다. 이미지 확대는 클릭 또는 키보드로 열고 Escape 및 닫기 버튼으로 닫을 수 있습니다.
