01 / CYCLE TIME OPTIMIZATION

PROJECT NOTES

복귀 위치와 병렬 동작을 조정해
총 동작 시간을 11.8% 단축

기준 / 복귀 60 mm173.3 s
복귀 위치 140 mm155.3 s
병렬 동작 추가152.8 s

전체 공급 + 창고 비움 시간의 합.
(173.3 − 152.8) ÷ 173.3 × 100 ≈ 11.8%
발표자료의 비교 측정값이며, 반복 횟수와 편차는 별도로 기록되지 않았습니다.

측정하며 조정한 두 가지

01

중간 복귀 위치를 60~140 mm, 20 mm 간격으로 변경하며 시간을 비교했습니다. 140 mm에서 총 18.0초를 줄였습니다.

02

분배 후 다음 소재를 바로 공급하는 병렬 동작을 적용해 추가로 2.5초를 줄였습니다.

트러블슈팅 / 레지스터 충돌

TTMR의 계측 영역 D3000과 내부 사용 영역 D3001을 확인하던 중, 합계 저장 주소가 D3001과 겹친 것을 찾았습니다. 합계 저장 영역을 분리해 충돌을 해결했습니다.

공정 시간 개선 결과

총 동작시간 173.3 → 152.8초, 20.5초 단축(11.8%). 병렬 동작 적용으로 2.5초를 추가 단축했습니다.

PROJECT NOTES

정지 상태 자이로 Bias 보정

3초 동안 249개 샘플을 수집한 실험에서 축별 편향을 측정하고 보정했습니다.

축 보정 전 보정 후

측정 조건: 정지 상태의 자이로 센서 / 3초간 249개 샘플.

주행에 적용한 제어 조건

입력

20 ms 센서 polling과 2 Hz 저역통과 필터. X/Y축 0.30 °/s, Z축 0.15 °/s deadband.

제어

Yaw 오차를 −180°~180°로 정규화하고 적분항 / 출력을 제한. 회전 / 정지 / 방향 전환 시 PID 상태를 초기화합니다.

연동

유효 주행 명령이 500 ms 동안 없으면 정지. 로봇팔 동작 / 보정 중 차량을 정지시키는 통합 인터록을 적용했습니다.

기술적 한계와 다음 검증

자력계가 없는 MPU6050의 상대 Yaw를 사용하므로 장시간 적분 드리프트가 남습니다. 실제 차체 진동과 하중 조건에서 PID 계수 및 직진 궤적 오차를 추가 검증할 수 있습니다.

근접 구간의 마커 유실에 대응

4개 마커의 16개 모서리로 보드 자세를 추정합니다. 정렬을 마치면 최종 직진 단계로 전환해, 가까워져 마커가 시야에서 벗어나도 마커 자세로 재조향하지 않도록 구성했습니다.

도킹 완료 조건IR 감지 + 실제 정지

최종 접근 중 IR HIGH를 확인한 뒤, 최신 오도메트리에서 정지 상태가 0.5초 유지되어야 DOCKED로 판정합니다. 입력 끊김이나 조기 정지를 도킹 성공으로 처리하지 않습니다.
